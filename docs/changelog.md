# Changelog

## [Unreleased]

Added <br>

- Budget unit changes ($'s, £s, and Euros)
- Budget "Units" column with a dropdown for hours, days, lump, and custom unit types; custom units are saved on the proposal for reuse
- Tick box to remove sub-total for budgets that don't have indirect
- PDF export cover page: centered dark-blue title at the top, Funder and Applicant on the left with Program and the date on the right, then the project summary below the cover header, followed by the proposal on a new page
- Hyperlinked table of contents on the first page of the HTML export, linking to each section

Changed <br>

- Cover page for preview and exports
- Timeline moved to follow Scope in the editor tabs, preview, and exports
- PDF export inserts a page break after the budget; the timeline no longer forces page breaks before or after itself
- Budget columns are now Task/Item, Units, Number, Cost/Unit, and Total; the old numeric "Units" column is now "Number"
- Budget Cost/Unit and Total cells no longer repeat the currency symbol — the Total header shows it instead (e.g. "Total ($)", "Total (£)", "Total (€)")
- HTML export header styled like the preview: title, Funder and Applicant, Program, then the date above the summary
- "Applicant Contact" renamed to "Applicant" throughout the app
- Dev server (`python run.py`) prints its startup banner once instead of twice, and the yellow "install python-dotenv" .env tip no longer appears

Fixed <br>

- Snippets repetition
- Cover letter addition/removal and applicants box
- Headings for sections vs. markdown within boxes

## 1.7.0

Added <br>

- Cover letter / letter of interest: new button in the Custom sections tab, rendered as the first section in preview and exports when enabled
- RFP import: paste RFP text directly or upload a .pdf file (text extracted per page) in addition to .json sections files and stock templates
- Budget by Year: the preview/exports toggle now works — the checkbox in the Budget tab saves `show_budget_by_year` and gates the table in preview, HTML, PDF, and Markdown exports
- Dynamic browser tab title: shows `Propongo - <proposal title>` (first 10 chars) when a proposal is open
- Expandable multi-line Applicant Contact field in the Scope tab
- Username or email accepted on the login page
- Password reset emails now include a clickable link (multipart HTML) and correct public URLs behind the Run/proxy
- Bot protection on registration: hidden honeypot field and per-IP / per-email rate limiting
- rfp reader from file for custom section

Changed <br>

- PDF/HTML/Markdown exports now include the cover letter when `cover_letter_include` is set
- Footer on every exported page: proposal title (bottom-left) and page number (bottom-right), excluded from the first page; last page shows "Proposal Generated by propongo.org"
- Budget-by-year table only rendered when the toggle is enabled
- SMTP settings (SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS, SMTP_FROM) now load from a `.env` file or the `Config` class, and failures to send reset emails are surfaced instead of silently ignored

Fixed <br>

- Budget by Year checkbox now persists and actually controls whether the table appears in preview and exports
- Password reset emails now send correctly (SMTP configuration fix)
- Budget-item timing normalized onto the budget item dict; legacy `budget_item_timings` is now a derived compatibility view

## 1.3.0

Added <br>

- Custom sections with Markdown formatting
- Excel import for spreadsheets
- Snippet library for reusable text blocks
- Live Markdown preview for custom sections
- Section reordering with up/down buttons
- Startup message when running propongo command
- Docstrings to all public functions and classes
- API reference documentation via mkdocstrings
- MkDocs documentation site at 3point.xyz/propongo

Changed <br>

- PDF export: reduced landscape margins (1.5cm → 0.8cm), widened task label column (70px → 160px)
- Added Templates section to usage documentation
- Custom regex markdown parser replaced with standard `markdown` library
- Centralized configuration in new `app/config.py`
- Comprehensive logging, type hints, and numeric input validation added
- Removed unused `Task` and `BudgetItem` dataclasses
- `_DATA_ROOT` path unified — no more platform-dependent divergence

Fixed <br>

- Graceful WeasyPrint failure on Windows with GTK3 install link
- Store proposals, templates, and snippets in Documents/Propongo/ instead of site-packages
- Include templates, static files, and snippets in installed package (missing in 1.3.2)
- End date now saves correctly even when no tasks exist (timeline dropdowns were guarded on `#timeline-inputs` which only renders with tasks)
- Timeline Gantt chart, preview, and export no longer enforce a 12-month minimum — actual project duration is respected
- End month now included in chart/preview/export (was off by one)
- Data directory now uses `~/Documents/Propongo/` consistently across all platforms (was `data/` relative to app source on Linux)
- Existing proposals in old `data/` directory are automatically migrated to the new path on first run
- Subtitle field missing from proposal list display on homepage and Switch Proposal modal
- Memory leak from unbounded proposal lock dictionary (switched to `WeakValueDictionary`)
- Duplicate export context code extracted to shared `utils.py`
- Standardized all error messages across the app
- Specific HTTP status codes for Excel import errors (400 vs 500)

Security <br>

- Replaced hardcoded secret key with `FLASK_SECRET_KEY` env var or secure random fallback
