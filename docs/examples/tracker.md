# Project Tracker Guide

Once a proposal is funded, the Project Tracker helps manage task progress, budget spending, milestones, and reporting.

## Accessing the Tracker

From the editor, open the **hamburger menu** and click **Project Tracker**. Each proposal has its own tracker.

## Dashboard KPIs

At the top of the tracker page, four cards show key metrics:

- **Tasks Completed** — overall completion percentage
- **Total Tasks** — count of all tasks
- **Total Budget** — planned budget including indirect costs
- **Milestones** — number of milestones set

## Tracking Task Progress

Each task from the proposal appears with:

- **Status** dropdown — Not Started, In Progress, Completed, Delayed
- **Progress** — slider (0–100%) for completion percentage
- **Dates** — actual start and end dates
- **Notes** — text area for observations

Changes save automatically.

## Budget Tracking

The budget table shows:

- **Item** name grouped by task
- **Planned** cost (from the proposal budget)
- **Actual** cost (editable — enter the real spend)
- **Variance** — calculated difference, color-coded (red for negative, green for positive)

## Milestones

- Click **Add Milestone** to create a new milestone with a name and date.
- Check the box to mark a milestone complete.
- Delete milestones with the trash icon.

## Reports

- Click **Add Report** to log a progress report with title, date, and content.
- Edit or delete reports as needed.

## Exporting Tracker Data

From the tracker page, export to **PDF**, **HTML**, or **DOCX** using the export buttons. The exported document includes the KPI summary, task status table, budget tracking, milestones, and reports.
