# Custom Sections Guide

Custom sections let you add unlimited Markdown-formatted content to a proposal, with live preview and reordering.

## Adding a Section

1. Switch to the **Custom Sections** tab.
2. Click **+ Add Section**.
3. Enter a **Title** (e.g. "Monitoring Plan", "Risk Assessment").
4. Write content in the Markdown editor on the left. The preview updates live on the right.

## Reordering Sections

Use the **Move Up** and **Move Down** buttons on each section to change its order. The order is preserved in preview and exports.

## Deleting a Section

Click the **trash icon** on a section to remove it. This cannot be undone.

## Importing Excel as a Section

Click **Import Excel** to upload a spreadsheet — it is converted to a Markdown table and added as a new section. See the [Excel Import guide](excel-import.md) for details.

## Using Snippets

Open the **Snippets** sidebar (toggle in the top-left) to insert reusable text blocks into any section editor. See the [Snippets guide](snippets.md).
