# Templates Guide

Templates let you save a proposal structure and reuse it for future projects.

## Saving a Proposal as a Template

1. Open a proposal in the editor.
2. Open the **hamburger menu** (top-left).
3. Click **Save as Template**.
4. Enter a name and optional category for the template.
5. Click **Save**.

The template stores the full proposal structure: scope, tasks, budget items, qualifications, custom sections, and timeline settings.

## Creating a New Proposal from a Template

1. From the homepage, click **Templates**.
2. Find the template you want to use and click **Use Template**.
3. A new proposal is created with all the template data filled in. Give it a new title and adjust as needed.

## Managing Templates

- View all templates at the **Templates** page.
- Delete a template by clicking the **trash icon**.

Templates are stored as JSON files in the `data/templates/` directory.
