Fixed: store proposals, templates, and snippets in Documents/Propongo2/ instead of site-packages
Added: docstrings to all public functions and classes
Added: API reference documentation via mkdocstrings
Added: MkDocs documentation site at 3point.xyz/propongo2

Added: startup message when running propongo2 command

Added: HTML export
